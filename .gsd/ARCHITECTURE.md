## Components

### Backend Services

#### Orchestrator (`backend/services/orchestrator.py`)
- **Purpose:** Coordinates the full SEC filing sync workflow
- **Flow:** Fetch submissions → Parse XML → Map CUSIPs → Store holdings
- **Dependencies:** SECClient, InfTableParser, DatabaseManager, CUSIPMapper

#### DatabaseManager (`backend/services/database.py`)
- **Purpose:** Database access layer for PostgreSQL
- **Key Features:** 
  - CRUD operations utilizing formal migrations
  - Separation of platform/canonical data (funds, holdings) and user data (tracking, groups)
  - Dashboard aggregation queries scoped by user
  - TWR (Time-Weighted Return) performance calculations
- **Canonical Tables:** funds, filings, holdings, prices, fund_quarterly_stats, fund_ingestion_status
- **User Tables:** users, user_tracked_funds, user_fund_groups, user_fund_group_members

#### SECClient (`backend/services/sec_client.py`)
- **Purpose:** EDGAR API integration for fetching 13F submissions
- **External API:** `https://data.sec.gov/`

#### InfTableParser (`backend/services/parser.py`)
- **Purpose:** Parse SEC 13F XML information table format
- **Handles:** Multiple XML schemas, PUT/CALL options, share quantities

#### CUSIPMapper (`backend/services/cusip_mapper.py`)
- **Purpose:** Map CUSIP identifiers to stock tickers
- **External API:** OpenFIGI or local cache database

#### PriceService (`backend/services/prices.py`)
- **Purpose:** Fetch historical stock prices for performance calculations
- **External API:** Yahoo Finance (yfinance)

#### SectorMapper (`backend/services/sector_mapper.py`)
- **Purpose:** Map stocks to sector classifications

#### MimicPerformanceCalculator (`backend/services/mimic_performance.py`)
- **Purpose:** Simulate "what if I followed this fund" performance
- **Key Feature:** Investment simulator with quarterly capital additions

## Data Flow

1. **User adds fund by CIK** → `POST /api/funds/{cik}/refresh`
2. **Orchestrator syncs SEC** → Fetches 10-year 13F history (new) or catches up (existing)
3. **Parser extracts holdings** → XML → structured holdings with CUSIP, shares, value
4. **CUSIPMapper enriches** → CUSIP → Ticker symbol
5. **Database stores** → filings + holdings tables
6. **Frontend fetches** → `/api/funds/{cik}/holdings` or `/api/dashboard/summary`
7. **Charts render** → Recharts visualizes historical composition and performance
